## Запуск

Склонируйте репозиторий:

```bash
git clone https://github.com/pravednovartem/slozhno-sosredotochitsya-ad.git
cd slozhno-sosredotochitsya-ad
```

Откройте `index.html` в браузере или запустите проект через расширение Live Server в редакторе кода. Установка зависимостей и сборка не требуются.
